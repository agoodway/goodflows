# Tasks

These tasks implement the delta specs; none are complete merely because the planning artifacts or experiment evidence exist. The [revision-6 lifecycle/identity report](https://ampcode.com/artifacts/goodflows-sprite-lifecycle-verification-measured-results-ab38d04a-b946-4c49-aa81-5490fe96416f) establishes bounded service/hold and separate caller-lock feasibility, not integrated acceptance. Live Sprite creation, process-loss tests, publication, and destruction require authorization for the exact disposable resources/endpoints. Never use retained benchmark Sprites as test fixtures; the lifecycle fixture also requires specific authorization for further use or destruction.

Live acceptance evidence counts only when the platform-reported organization was verified to be the authorized one. The first live run on 2026-11-07 reported platform organization `thomas-brewer` under the credential used, not the authorized `goodway`, so it is not authorized-scope acceptance. Authorized-scope acceptance for 1.2, 5.5, 8.3, 8.4, and 8.5 comes from the later rerun in `goodway`, whose platform-reported organization was verified before any mutation.
